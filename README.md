# Sales Data Analyzer using Python & Pandas

A professional data analysis project built using Python and Pandas to analyze product sales data from a CSV file.

## Features
- Read CSV data using Pandas
- Add TOTAL column automatically
- Calculate revenue per product
- Find total revenue
- Identify top-selling product
- Sort products by revenue
- Perform column-based operations

## Technologies Used
- Python
- Pandas
- CSV Dataset

## Dataset Format

```csv
PRODUCT,QUANTITY,PRICE
A,2,100
B,1,200
A,3,100
C,5,50
```

## Installation

```bash
pip install pandas
```

## Run the Project

```bash
python sales_analyzer.py
```

## Sample Output

```text
Total Revenue: ₹950
Top-Selling Product: A
```
